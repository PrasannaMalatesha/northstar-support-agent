# Order changes

## ORD-CANCEL

An order can be cancelled only when its status is placed. Packed, shipped, and delivered orders cannot be cancelled. A cancelled order is refunded in full, including outbound shipping that was charged. Cancellation waits for a person before it is recorded.

## ORD-MODIFY

Item quantities and sizes can be changed only while the status is placed. The specialist proposes the change. A person records it. If the status is packed or later, the customer must wait for delivery and then use the return rules.

## ORD-TRACK

Tracking facts are whatever the order record stores: status, ship date, and delivery date. If a date is empty, say it is not on the order. Do not invent a carrier name, a tracking number, or a scan event.
