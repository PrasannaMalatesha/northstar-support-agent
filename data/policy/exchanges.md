# Exchanges

An exchange swaps the same item for another size or color. It is not a new product and not a refund, unless a section here says otherwise.

## EXC-ELIGIBILITY

**Rule**: Apparel and footwear, and bags and accessories, may be exchanged for the same item in a different size or color at the same price. The request must be inside the return window in REF-CATEGORY, and the item must be unworn with tags on. Home and kitchen, and small electronics, are not exchanged. Those lines follow the returns handbook.

**Applies when**: The customer wants a different size or color of the item they received.

**Agent must not**: Exchange a different product, a home item, or an electronic item under this rule.

**Example**: A coat in medium, unworn, inside the apparel window, can move to large if the price is the same. The draft cites EXC-ELIGIBILITY.

## EXC-STOCK

**Rule**: An exchange is offered only when the catalog row for the requested size or color says in stock. If that row says not in stock, the case is a return under the returns handbook, not an exchange.

**Applies when**: The customer has named the size or color they want.

**Agent must not**: Promise a size that the catalog row does not show as in stock, or invent a restock date.

**Example**: Large is the wanted size and the catalog row says not in stock. The specialist offers a return instead. The draft cites EXC-STOCK.

## EXC-LIMIT

**Rule**: Each order line may be exchanged once. A second size change on that line is a return, not another exchange.

**Applies when**: The line already has an exchange recorded.

**Agent must not**: Offer a second exchange on the same line.

**Example**: A shirt already moved from small to medium. A later ask for large is a return. The draft cites EXC-LIMIT.

## EXC-PROCESS

**Rule**: The replacement ships when the return scan is recorded. Shipping is free in both directions. The replacement is the same price, so no extra charge and no partial refund is created for the swap itself.

**Applies when**: An exchange has been approved and the customer asks what happens next.

**Agent must not**: Charge a label fee from REF-SHIP-COST on an eligible exchange, or ship the replacement before the return scan.

**Example**: The medium coat is scanned at the carrier. The large coat then ships, with no shipping charge either way. The draft cites EXC-PROCESS.

## EXC-DIFFERENT-ITEM

**Rule**: A request for a different item, not a different size or color of the same item, is a return plus a new order. The return follows the returns handbook. The new order is placed by the customer. Support does not place it.

**Applies when**: The customer names a different product.

**Agent must not**: Call a different product an exchange, or place the new order from the case desk.

**Example**: The customer wants a hat instead of the coat. The coat is a return. The hat is a new order the customer places. The draft cites EXC-DIFFERENT-ITEM.

## REP-REPLACEMENT

**Rule**: A damaged or defective item is replaced with the same item when the catalog row says in stock and the report is inside REF-DAMAGED, or inside warranty coverage under WAR-COVERAGE. If the row says not in stock, the remedy is the refund in REF-DAMAGED or WAR-REMEDY. A replacement is not an exchange under EXC-ELIGIBILITY.

**Applies when**: The customer wants the same item again because it arrived damaged or has a defect.

**Agent must not**: Offer a different color as the replacement unless the customer asks and EXC-ELIGIBILITY also applies.

**Example**: A cracked mug is in stock. The proposal is a replacement of that mug, citing REP-REPLACEMENT. If the mug row says not in stock, the proposal is the damage refund instead.
